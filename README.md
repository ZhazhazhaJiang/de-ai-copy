# 去除 AI 味

通过持续积累用户指出的 AI 味句子，建立我们自己的反向检查库。文案写好后，逐条运行 checklist，删改命中的表达。

## 当前内容

- [反向检查库](rules/negative-checklist.md)：第一期 4 个反例归为 3 条规则，保留用户原句、提炼、同类变体和改写例。
- [审核与吸纳流程](docs/review-workflow.md)：怎么检查成稿，怎么吸收新反馈。
- [审核提示词](prompts/final-review.md)：与当前规则库一起使用。

规则由用户反馈逐步生长。每次用户指出一句话 AI 味重，就记录原句、提炼模式并补入 checklist；重复模式合并维护。

项目及后续审核采用独立设计。当前工作文档已移除此前的外部调研及派生规则，旧内容仅保留在 Git 历史中。

## 使用

审核时提供成稿，按需补充使用场景。默认返回修改后全文；需要查看依据时，再列命中的规则编号和改动。

新增反馈时直接说“这句话 AI 味很重”并给出句子，助手会更新规则库。本项目中的答复和审核说明也执行同一份 checklist。

当前已有规则库和可人工使用的提示词，后续再接入文案生成流程末尾。
