# 中文文案的 AI 味：审核候选与判断条件

调研日期：2026-10-12。这里的“AI 味”指读者感受到的模板化、空泛和不合语境，不是作者身份鉴定。

## 能够精确到什么程度

本次没有取得有代表性、带来源标签的中文人类／模型文案对照语料，因此不能声称哪些中文词的出现概率最高，或给词汇排一个科学的“AI 浓度榜”。以下优先级来自开源编辑规则和本项目的中文编辑判断，后续需要真实文案验证。

英文有较明确的群体统计证据。Kobak 等研究了 2010—2024 年超过 1500 万篇 PubMed 摘要；论文 v5 的第 2.1 节报告，2024 年 `delves`、`underscores`、`showcasing` 的出现频率相对研究所估计预期值之比分别为 28.0、13.8、10.7。它们不是“含这个词就有多少概率是 AI”，也不是中文对应译词的风险值。论文还区分了相对增长与绝对增长，不能直接混成一张排名表。[论文摘要](https://arxiv.org/abs/2406.07016)／[全文 v5](https://arxiv.org/html/2406.07016v5)。

开源 Skills 提供的是编辑经验：[Humanizer](https://github.com/blader/humanizer/blob/main/SKILL.md) 与 [Humanizer-zh](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md)覆盖夸大意义、宣传语气、空泛归因、否定式排比、机械结构等。它们的规则条数和词表不是经过统一实验验证的检测指标。项目选择及许可详见[调研](open-source-research.md)。

## 优先检查哪些词和表达

“高”表示当触发条件成立时优先修改；“中”表示必须结合篇幅、体裁和作者语气判断。下表具体中文措辞由本项目归纳或自拟，并非每个词都逐字来自上游。

| 优先级 | 候选词／表达 | 成为问题的条件 | 编辑动作与应保留的情况 |
| --- | --- | --- | --- |
| 高 | 赋能、助力、驱动、引领 | 不交代谁做什么、解决什么问题 | 用已有事实写动作；“电机驱动风扇”是准确描述，保留 |
| 高 | 重塑、重构、颠覆、革新 | 把局部改动说成行业变化，没有对应证据 | 缩回可证实的变化；技术上的“重构模块”可保留 |
| 高 | 开启新篇章、迈向新高度、注入新活力、树立新标杆 | 只表达赞扬，不提供事件或结果 | 删除虚浮判断，留下实际发生的事；正式引文不擅改 |
| 高 | 具有里程碑意义、彰显、凸显、充分体现 | 强行从小事实推导宏大意义 | 保留事实并收窄结论；确有论证的意义判断可保留 |
| 高 | 极致、卓越、全方位、一站式、前所未有 | 没说明范围、比较对象或依据 | 写已有功能和范围；正式产品名称、已证实覆盖范围除外 |
| 高 | 无缝、轻松、高效、显著、大幅 | 遮掉操作成本、使用限制或比较基准 | 核对原有证据；“耗时从 10 分钟降到 2 分钟”无需删掉结论 |
| 高 | 专家认为、业内普遍认为、研究表明、数据显示 | 没有可追溯来源，却以权威语气背书 | 列为待核实；不能为了自然而编专家、编研究 |
| 高 | 底层逻辑、顶层设计、生态、矩阵、闭环、抓手 | 术语堆叠却说不清主体、对象、动作 | 改成真实动作或追问所指；业务定义、系统术语保留 |
| 高 | 本质上、归根结底、说到底、真正的核心在于 | 把可讨论的解释包装成唯一答案 | 说明具体判断与条件；有论证支撑的归纳可保留 |
| 中 | 值得注意的是、值得一提的是、重要的是、事实上、显然 | 删除引导词后信息不变，或频繁提醒读者重视 | 通常直接写信息；“值得注意的是，退款不含手续费”可以保留，也可简化 |
| 中 | 随着……不断发展、在当今……时代、在……的大背景下 | 与后文结论无必要关系，只作通用开头 | 从当前对象或事件起笔；必要的历史背景保留 |
| 中 | 深入探讨、全面解析、深度剖析、多维度解读 | 宣告将要讲解，却不进入内容 | 直接进入问题；目录标题或明确内容预告可保留 |
| 中 | 此外、与此同时、首先／其次／最后、综上所述、总而言之 | 段落逻辑靠连接词假装成立，或结尾只重述正文 | 先检查实际关系再删改；教程步骤、长报告总结保留 |
| 中 | 不仅……更……、不仅仅是……更是……、不是……而是…… | 后半句只是抬高气势，前后没有真实递进或对比 | 把可证实的判断直说；“不是自动扣款，而是手动续费”必须保留 |
| 中 | 无论你是……还是……、从……到…… | 为覆盖所有人强行凑人群或范围 | 按实际受众写；确实适用多个群体时保留准确范围 |
| 中 | 让我们一起、未来可期、携手共创、共同见证 | 无行动入口的口号收尾，与文案目标无关 | 删除或留下原稿已有行动；有意使用的活动口号按品牌要求保留 |
| 中 | 宝子们、家人们、绝绝子、狠狠拿捏、真的太……了 | 与品牌、作者或渠道不匹配，用热词代替内容 | 恢复指定语气；作者惯用且受众接受时保留 |
| 中 | 你是否也曾……、想象一下……、有没有一种可能…… | 无依据代入读者感受，重复套路开头 | 改为具体问题或场景；确有必要的提问不机械删除 |

## 通常比单词更影响读感的结构

1. **假对比和概念拔高。** “这不仅是一次更新，更是一场体验革命。”前半句是事实，后半句没有新增可核查内容。
2. **抽象词连续出现。** “以多维矩阵驱动生态协同，形成增长闭环。”读者无法据此知道做了什么。抽象词数量本身不是判定阈值。
3. **每段同一个模版。** 反复“首先……其次……最后……”，每节三点，末尾再总结一次。真正的步骤说明仍可使用编号。
4. **情绪强于事实。** 大量“震撼、重磅、极致”，却没有活动内容、适用对象和下一步。
5. **无来源的具体性。** 为了“像真人”新增亲历、客户评价或精确数字。读起来更具体也不代表更好，审核必须拦截这种改写。
6. **刻意制造口语感。** 随意塞入“说实话、怎么说呢、懂的都懂”，打乱句子、加错别字或强行自嘲。是否自然仍取决于作者和渠道。
7. **模型对话残留。** 成稿中混入“当然可以”“以下是优化后的版本”“希望对你有所帮助”，或与发布内容无关的写作说明。若文稿本身引用这些话，则按引用保留。

破折号、加粗、排比、三项列举、短句都可以正常使用；只有不合体裁、没有信息作用或反复出现时才提示。

## 审核时的四个问题

- 这句话提供了什么可定位的信息：主体、动作、对象、条件、证据或真实感受？
- 删除候选表达会丢失什么含义？若没有损失，是否直接删除更清楚？
- 所谓具体化是否有原稿或用户资料支撑？没有支撑就保留缺口。
- 这个表达是作者惯用语、必要术语或品牌固定文本吗？是的话先保护，再判断周围内容。

## 后续如何把候选变成可靠词表

从用户实际使用的渠道收集文案和人工认可的终稿，按体裁分别标出“应改／可保留／待核实”，保留判定理由。先用未参与调规则的稿件盲比原稿和终审稿，记录哪一版更合适以及误删的信息。

如果以后要研究“模型偏好词”，需额外取得同题、同体裁、同长度范围的人类／模型对照样本，按每千字或文档出现率统计，并报告样本量、时间、模型和不确定性。编辑偏好与来源分类分别评估；在此之前，不给本表贴“高频实证榜”标签。
